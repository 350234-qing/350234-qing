## 💡 我的三个习惯

**1. 先想"什么情况下会坏"**
错题重生的三模式降级、推送系统的补投重试、公假系统的越权防护——都是设计阶段先问"断网了怎么办""被人乱用怎么办"，再写代码。

**2. 密钥不碰前端**
小程序能反编译，所以 AI Key 全部走云函数环境变量；仓库里所有真实 Token 都替换成占位符。

**3. 交付要能被别人跑起来**
每个仓库都有完整 README：为什么做、怎么跑、结构是什么、哪些做了哪些没做。
